# Запрос на партнёрский API для ЛекСкана

**Тема:** Запрос партнёрского API: поиск лекарств по МНН и сравнение цен в Telegram Mini App

Здравствуйте!

Мы разрабатываем «ЛекСкан» — бесплатный Telegram Mini App, который помогает пользователям в городах России находить лекарства по действующему веществу (МНН) и сравнивать предложения аптек с учётом дозировки, лекарственной формы и упаковки.

Сейчас у нас работает прототип, но реальные цены не отображаются до получения официального доступа к данным.

Хотели бы обсудить возможность партнёрской интеграции. Уточните, пожалуйста:

1. Предоставляете ли вы API или разрешённую выгрузку для **чтения розничных цен, наличия и адресов аптек** по городу, а не только API для передачи остатков от аптек?
2. Какие регионы, аптечные сети и поля доступны? Какова частота обновления цен/остатков?
3. Разрешается ли отображать ваши предложения и ссылки на страницы аптек внутри стороннего Telegram Mini App? Какие требования к атрибуции данных и брендингу?
4. Есть ли тестовый доступ, ограничения запросов, стоимость, условия кэширования и коммерческого использования?
5. Доступны ли идентификаторы ЕСКЛП/ГРЛС или другие данные для точного сопоставления МНН, дозировки, формы и упаковки?
