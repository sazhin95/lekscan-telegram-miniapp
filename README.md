# ЛекСкан · Telegram Mini App

Публичный прототип для поиска лекарств по МНН и сравнения **сопоставимых** аптечных предложений. Работает без сборщика: файлы можно размещать на GitHub Pages. Бот: `@scanlek_bot`.

## Что реализовано

- Поиск по четырём примерам действующих веществ/известных названий, выбор города, дозировки, формы и упаковки.
- Ссылки на **настоящие сайты** Apteki.su, Ютека и Мегаптека. Сайты открываются на главной: город и запрос нужно выбрать на стороне сервиса.
- Кнопка копирования полного запроса, чтобы искать его на сайтах аптек.
- Отдельный и **выключенный по умолчанию** демонстрационный режим с вымышленными ценами.
- Чтение локального `offers.json` (или endpoint из `window.LEKSCAN_CONFIG.offersUrl`) с фильтрацией строго по МНН/форме/дозировке/упаковке/городу.
- Проверка цены, HTTPS-ссылки, даты обновления (не старше 24 часов), названия источника и статуса наличия. Устаревшие/неполные/невалидные записи скрываются.
- Избранное и выбранный город сохраняются только в браузере пользователя.

## Чего пока нет

**Подключённого разрешённого источника цен НЕТ.** `offers.json` содержит пустой массив, поэтому реальные цены приложение не показывает. Нет бронирования, автопоиска по всем аптекам РФ, уведомлений, персонального кабинета и серверной синхронизации. Нельзя считать ссылки на внешние сайты доказательством доступности товара. Перечень городов — для демонстрации интерфейса.

## Как добавить разрешённый источник цен

1. Согласовать API/лицензию с агрегатором или аптечной сетью. Документация Apteki.su о партнёрском API: https://www.apteki.su/webmaster/.
2. Использовать отдельный сервер (например Cloudflare Worker) или санкционированный серверный процесс, который хранит API-ключ **только в серверном секрете**, запрашивает нужные города и обогащает данные каталога.
3. Возвращать `/offers` API или публиковать разрешённый JSON-файл в точно определённом формате ниже. `offers.json` нельзя заполнять скопированными с чужого сайта ценами без прав на использование.
4. Проводить обязательное сопоставление идентификатора препарата/МНН, лекарственной формы, дозировки, упаковки, адреса и региона до вывода результата. Не смешивать комбинированные препараты и одиночные МНН, не трактовать одинаковое МНН как автоматическую возможность замены.
5. Показывать наименование источника и дату цен, не заявлять «самая дешёвая в городе», если покрытие неполное.

### Формат `offers.json` (структура примера, не реальная цена)

```json
{
  "version": 1,
  "offers": [
    {
      "id": "example-record-1",
      "city": "Иваново",
      "productId": "ibuprofen",
      "form": "Таблетки",
      "dose": "200 мг",
      "pack": "20 шт.",
      "pharmacyName": "Название аптеки из источника",
      "pharmacyAddress": "Адрес из источника",
      "price": 123.45,
      "currency": "RUB",
      "availability": "in_stock",
      "updatedAt": "2026-11-20T00:00:00Z",
      "sourceName": "Имя партнёрского источника",
      "sourceUrl": "https://example.org/actual-offer"
    }
  ]
}
```

**Этот JSON приведён только для описания структуры, а не как доступное аптечное предложение.** Дата должна быть актуальной в момент получения, поле `availability` — `in_stock` или `unknown`.

В `index.html` подключён `real-offers.js`, затем `app.js`. По умолчанию загрузка идёт из `./offers.json`. Если позже будет собственный сервер, до `app.js` можно добавить:

```html
<script>window.LEKSCAN_CONFIG = { offersUrl: 'https://api.example.org/offers' };</script>
```

Потребуется разрешить CORS только для домена приложения и, при необходимости, ограничить запросы. Никогда не публикуйте API-токены в JavaScript, репозитории или скриншотах.

## Локальная проверка

```bash
node test-offers.cjs
python -m http.server 8080
```

Откройте http://localhost:8080. Демо включается только переключателем внизу результатов.

## Публикация

`Settings → Pages → Deploy from branch → main → / (root)`. Адрес текущего проекта:
https://sazhin95.github.io/lekscan-telegram-miniapp/

В BotFather выберите `@scanlek_bot` и проверьте корректный Mini App URL. Изменения из `main` автоматически публикуются после успешной сборки GitHub Pages.

## Приватность и безопасность

Этот статический прототип не собирает Telegram `initData` и не отправляет пользовательскую медицинскую информацию на сервер ЛекСкана. Браузер хранит избранное локально. При переходе на сторонний сайт действует его политика конфиденциальности. При добавлении сервера потребуется отдельная политика обработки данных, защита API, проверка подписанных данных Telegram и юридическая оценка требований к медицинской/рекламной информации.
